# Live2D Copilot 产品介绍

## 概述

Live2D Copilot 是 AI-Zen 正在开发的一款 **AI 桌面宠物（Live2D）** 应用。它以一个常驻桌面的 Live2D 角色（默认模型为「虹色Mao」）为载体，集成 AI 对话、流式语音合成（TTS）与桌面级交互能力，目标是打造一个“看得见、听得见、可对话”的桌面伙伴。

- **产品定位**：桌面端 AI 助手 / 桌宠。
- **目标平台**：桌面（Windows 优先，基于 Tauri 2）。
- **发布计划**：拟发布 **Steam**（详见「开发进度」）。
- **当前版本**：`0.1.0`（早期开发版本）。
- **包名**：`live2d-copilot`（`package.json` 中为 `private: true`，为桌面应用项目，非对外发布的 npm 库）。

## 它解决什么问题

传统助手多为页面/工具形态；Live2D Copilot 尝试以“拟人化角色”的方式提供陪伴与效率价值：

- 在桌面常驻一个会“看你”、会“说话”、可拖拽、可穿透鼠标的 Live2D 角色。
- 通过对话与 TTS 形成“说—听—答”的闭环交互体验。
- 作为桌宠的同时，保持轻量、可直接在桌面操作。

## 核心特性速览

- **透明无边框桌宠窗口**：500×600，始终置顶，无边框。
- **Live2D 渲染**：基于 `@ai-zen/live2d-vue`，默认模型「虹色Mao」。
- **AI 对话**：接入 DeepSeek / ChatGLM，流式输出。
- **语音合成**：Edge-TTS（浏览器 WebSocket 直连）。
- **桌面交互**：系统托盘、原生窗口拖动、滚轮缩放、鼠标穿透、全局视线追踪。
- **设置面板**：配置 API Key、模型、TTS 语音。

## 当前状态

- 版本 `0.1.0`。
- 属于**早期开发版本**，整体架构与核心对话链路已打通。
- 模型管理、插件管理、设置持久化、i18n、Steam 集成等仍为**待完成**项（详见进度页）。
